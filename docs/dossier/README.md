# Validation dossier

These documents describe what LiteraSift's audit trail and electronic signatures actually do, how that is
tested, and what they do not do. They are a starting point for a company's own validation, not a certificate:
a regulated user must still run their own risk assessment, qualification and procedures.

| File | Purpose |
| --- | --- |
| `01-urs.md` | User requirements |
| `02-risk-assessment.md` | Risks, controls, residual risk |
| `03-design-specification.md` | How it is built |
| `04-verification.md` | Tests and how to run them |
| `05-traceability.md` | Requirement → design → test |
| `06-monitoring.md` | Day-to-day operation and verification |
| `07-regulatory-crosswalk.md` | Mapping to electronic-records expectations; gaps stated plainly |
